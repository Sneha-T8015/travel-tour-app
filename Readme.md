# Travel & Tour Web Application

## 📌 Overview

A full-stack web application for exploring travel destinations and tours.

## 🛠️ Tech Stack

* Frontend: React + Tailwind CSS
* Backend: Python (Flask/FastAPI)
* Database: SQL

## 🚀 Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/Sneha-T8015/travel-tour-app.git
cd travel-tour-app
```

---

### 2. Backend Setup

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip3 install -r requirements.txt
```

Run backend:

```bash
python3 app.py
# OR
uvicorn main:app --reload
```

---

### 3. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
